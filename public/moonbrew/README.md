# Moonbrew Magic Café — ใบเสร็จ HTML

เปิด `receipt.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งแพ็กเกจหรือเชื่อมต่ออินเทอร์เน็ต

- กด “แก้ไขข้อมูล” เพื่อเปลี่ยนข้อมูลใบเสร็จและรายการสินค้า
- กด “ออกใบเสร็จ” เพื่อคำนวณยอดและแสดงข้อมูลใหม่
- กด “พิมพ์ / บันทึก PDF” แล้วเลือก Save as PDF ในหน้าต่างพิมพ์
- เลือก A4, scale 100%, ปิด header/footer ของเบราว์เซอร์
- เกิน 4 รายการจะแบ่งหน้าอัตโนมัติเพื่อรักษาตำแหน่งและสัดส่วนต้นฉบับ ยอดรวมแสดงในหน้าสุดท้าย
- คอลัมน์ราคา = จำนวน × ราคาต่อหน่วย ตัวอย่าง Moon Scone คือ 2 × 60 = 120
- ตัวอย่าง: 445 − 20 + ภาษี 29.75 = 454.75

## ใช้กับเว็บเดิม

คัดลอก `receipt.css`, `receipt.js`, โฟลเดอร์ `assets` และโครง HTML จาก receipt.html ลงในหน้าใบเสร็จของเว็บ หรือนำหน้า receipt.html ไปเปิดใน iframe ที่อยู่ origin เดียวกัน

หลังโหลดสคริปต์ เรียก:

```js
window.MoonbrewReceipt.render({
  number: 'MB-0724',
  date: '19/09/2026',
  time: '10:45',
  staff: 'Luna',
  table: '07',
  items: [
    { name: 'Butterbrew Latte', quantity: 1, unitPrice: 95 },
    { name: 'Moon Scone', quantity: 2, unitPrice: 60 },
    { name: 'Stardust Cake', quantity: 1, unitPrice: 145 },
    { name: 'Crystal Tea', quantity: 1, unitPrice: 85 }
  ],
  discount: 20,
  taxRate: 7,
  paymentMethod: 'Galleon Card',
  status: 'ชำระแล้ว'
});
// คืนค่า { sub:44500, discount:2000, tax:2975, total:45475 } หน่วยสตางค์
await window.MoonbrewReceipt.print();
```

`getData()` คืนข้อมูลออร์เดอร์ปัจจุบัน ตัวเลข unitPrice และ discount รับหน่วยบาท ส่วนการคำนวณใช้จำนวนเต็มหน่วยสตางค์ ปัดภาษีหลังหักส่วนลด

## ภาพและข้อความ

ภาพต้นฉบับเป็น artwork ฐานเต็มขนาด 941 × 1672 พิกเซล ส่วนข้อมูลใบเสร็จถูกปิดด้วยกระดาษที่ลบข้อความออกแล้ว และแทนที่ด้วยข้อความ HTML จริง จึงคงโลโก้ นกฮูก ไม้กายสิทธิ์ ขอบกระดาษ และของตกแต่งจากต้นฉบับโดยตรง

- `assets/receipt-original.png` — ต้นฉบับสำหรับชั้นลวดลาย
- `assets/receipt-background.png` — ภาพที่ลบข้อมูลตัวอย่างออก
- `receipt.css` — ฟอนต์ ตำแหน่งข้อความ และรูปแบบพิมพ์
- `receipt.js` — API ข้อมูลสินค้า คำนวณยอด แบ่งหน้า และแบบฟอร์ม
- `preview.png` — ภาพตัวอย่างที่เรนเดอร์จาก HTML

ภาพพื้นหลังจัดทำด้วยเครื่องมือสร้าง/แก้ไขภาพในตัว โดยสั่งลบเฉพาะข้อมูลออร์เดอร์และรักษาภาพเดิม ชั้นภาพต้นฉบับยังถูกใช้รักษาลวดลายจริงไว้ ฟอนต์ HTML ใช้ Nimbus Roman และ Noto Serif Thai ที่แนบมา จึงใกล้เคียงแต่ไม่ใช่การคัดลอกตัวอักษรในภาพแบบพิกเซลต่อพิกเซล ข้อความยาวจะลดขนาดให้พอดีช่อง

ไฟล์ standalone ที่ส่งแยกฝังภาพ ฟอนต์ CSS และ JavaScript ทั้งหมดไว้แล้ว สามารถย้ายไฟล์เดียวได้ ส่วน ZIP นี้แยกไฟล์เพื่อแก้ไขและติดตั้งในเว็บสะดวก
